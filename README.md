# huang-kc.github.io

Personal academic homepage of **Kaichen Huang (黄楷宸)** — Ph.D. Student at the
College of Computing and Data Science, Nanyang Technological University.

🔗 **Live:** https://huang-kc.github.io

## About

A clean, single-page academic site covering education, news, publications
(with teaser figures and collapsible abstracts), experience, honors, and
academic service. It is a self-contained `index.html` (vanilla HTML / CSS / JS)
served via GitHub Pages — no framework, no build step.

## Structure

```
index.html    the whole page (inline CSS + JS)
assets/       avatar, calligraphy name, publication teasers, org logos, CV
.nojekyll     serve files as-is (skip Jekyll)
```

## Features

- Light / dark theme toggle (follows the system by default; choice is remembered)
- Publication cards with figures and expandable abstracts
- Scrollable news timeline and mentor-linked experience
- Responsive and theme-aware throughout
